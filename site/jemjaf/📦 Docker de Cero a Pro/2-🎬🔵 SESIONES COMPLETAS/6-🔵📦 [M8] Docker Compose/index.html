[M8] DOCKER: DE CERO A PRODUCCIÓN 🚀

Llegamos al módulo final de nuestro curso. Cerramos con broche de oro aprendiendo a orquestar múltiples servicios sin volvernos locos con comandos interminables en la terminal.

Aquí el resumen de lo que cubrimos:

  • Docker Compose: Dejamos de levantar contenedores uno por uno y aprendimos a definir un stack completo \(como una API y su Base de Datos\) usando un solo archivo YAML declarativo.
  • Moderno vs Legacy: Le dijimos adiós definitivo al antiguo comando docker-compose \(con guion\) y eliminamos la directiva version: de nuestros archivos, adaptándonos al estándar moderno.
  • Variables y Resiliencia: Vimos cómo proteger nuestros secretos inyectando variables a través de un archivo .env. También configuramos la política restart: unless-stopped para garantizar que nuestras aplicaciones se recuperen solas en producción si algo falla.
  • Anti-patrones: Revisamos las malas prácticas clásicas que debemos evitar a toda costa, como colocar contraseñas en texto plano dentro del YAML o usar depends_on sin asegurarnos de validar el estado con un healthcheck \(condition: service_healthy\).

    Para validar lo aprendido y que sigan ensuciándose las manos, les dejo estos dos súper recursos oficiales de Docker:
    📖 Glosario de Docker: Ideal para validar todo el vocabulario técnico del curso: [https://docs.docker.com/reference/glossary/](https://docs.docker.com/reference/glossary/)
    🛠️ Ejemplos Oficiales: El repositorio de oro con plantillas listas de Dockerfiles y Compose en múltiples lenguajes, frameworks y bases de datos: [https://docs.docker.com/reference/samples/](https://docs.docker.com/reference/samples/)

    Gracias a todos por llegar hasta aquí. Espero que este curso les haya dado una nueva forma de pensar y construir aplicaciones. Mi mayor éxito será que sigan practicando y que, algún día, sean mejores que yo.

    ¡Pero esto no termina! Nos vemos mañana para integrar todo esto en el proyecto de CI/CD completo.

    Saludos y, como siempre... ¡a seguir rompiendo y levantando contenedores! 🚀
