🌐 [Parte II] Arquitectura Web 101

¡Hola a todos! 👋En esta clase subimos de nivel para entender las piezas fundamentales que viven detrás del servidor y cómo escalan los sistemas en producción.

Aquí tienen el desglose exacto de lo que cubrimos:

  • Navegadores y el ecosistema Chromium: Entendimos el rol del motor en los navegadores y cómo auditar compatibilidad y comportamiento con herramientas clave como Can I Use, Internet Archive \(Wayback Machine\) y pruebas de localización con Geotargetly.
  • Persistencia de Datos \(SQL vs. NoSQL\): Cuándo usar bases de datos relacionales tradicionales frente a motores NoSQL orientados a documentos como MongoDB. Además, sumamos el rol crítico de Redis como base de datos en memoria para gestionar caché y altísima velocidad.
  • Mapeo y Conexión \(ORM\): Qué es un Object-Relational Mapping y cómo nos permite interactuar con la base de datos usando nuestro lenguaje de programación sin escribir sentencias SQL en bruto por todo el código.
  • Integración y Exposición \(APIs & API Gateway\): Cómo comunicamos los servicios y por qué un API Gateway es el guardia de tráfico indispensable para gestionar autenticación, ruteo y límites de peticiones en sistemas modernos.
  • Evolución Arquitectónica: El cara a cara entre Monolito vs. Microservicios. Analizamos las ventajas, los costos operativos y cuándo realmente vale la pena dividir un sistema en servicios independientes.
  • Asincronía y Desacoplamiento \(Colas\): Cómo evitar que los servicios colapsen delegando tareas pesadas mediante sistemas de mensajería, diferenciando los modelos Pull-based \(el consumidor pide el trabajo\) y Push-based \(la cola empuja el mensaje al consumidor\).

    Comprender estas piezas es indispensable para diseñar infraestructuras sólidas, saber qué bases de datos desplegar en la nube y entender cómo conectar nuestros microservicios dentro de un clúster.

    ¡A repasar la sesión y tomar nota!
