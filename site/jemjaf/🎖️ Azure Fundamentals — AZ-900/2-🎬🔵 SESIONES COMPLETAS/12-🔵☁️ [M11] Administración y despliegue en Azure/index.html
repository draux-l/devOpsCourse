☁️ [M11] Azure Fundamentals (AZ-900): Herramientas de Administración

Qué tal equipo, ya llegamos al módulo de herramientas para gestionar y desplegar recursos \(Dominio 3\). Les dejo el resumen directo para el examen y la práctica.

💻 Línea de comandos \(Enfoque Imperativo\)

  • Azure CLI funciona en múltiples plataformas y usa comandos que empiezan con 'az'

    • Azure PowerShell trabaja con objetos y emplea el módulo Az siguiendo la sintaxis Verbo-AzSustantivo
      Para preparar su entorno local de PowerShell instalen el módulo oficial usando el comando:
      • Install-Module -Name Az -Repository PSGallery -Force

        • Azure Cloud Shell es la consola directamente integrada en el navegador que ya viene autenticada y guarda sus archivos mediante almacenamiento persistente en Azure Files

          🏗️ Infraestructura como Código \(Enfoque Declarativo\)

          • Plantillas ARM o ARM Templates son archivos JSON idempotentes que describen el estado final deseado de la infraestructura:

            Antes de lanzar la siguiente plantilla de prueba asegúrense de cambiar el nombre del grupo de recursos por el que tengan en la cuenta de la comunidad o suyo propio

            • az deployment group create --resource-group rg-demo-arm --template-file storage.json --parameters storageAccountName=stdemojemjaf123 environmentName=PROD

              • Bicep es el lenguaje nativo recomendado por Microsoft que ofrece una sintaxis mucho más simple y limpia que el JSON clásico

                🌍 Gestión Híbrida y Ciclo de Vida

                • Azure Arc extiende el plano de control de Azure para administrar e inventariar servidores locales \(on-premises\) u otras nubes
                • El ciclo de vida de las características avanza de Private Preview a Public Preview y finalmente alcanza su madurez en General Availability o GA

                  • Azure DevOps Services centraliza el trabajo de desarrollo usando Azure Boards para la planificación, Azure Repos para guardar código con Git y Azure Pipelines para automatizar entregas y despliegues
