☁️ [M08] Azure Fundamentals (AZ-900): Identidad, Acceso y Seguridad

Entramos a uno de los dominios más cruciales \(y evaluados\) del examen. Tomen nota de las diferencias clave y los nombres oficiales para que no los sorprendan:

🔐 Identidad y Acceso \(Identity & Access\)

  • AuthN vs. AuthZ: La Authentication \(Autenticación\) verifica quién eres \(ej. login, MFA\); la Authorization \(Autorización\) define qué puedes hacer mediante roles.
  • Microsoft Entra ID: Es el directorio de identidad en la nube \(antes Azure AD\). Ojo a la trampa clásica: el Tenant \(inquilino\) controla quién eres, mientras que la Subscription \(suscripción\) controla quién paga.
  • Microsoft Entra Domain Services: Proporciona controladores de dominio administrados \(LDAP, Kerberos\) para aplicaciones heredadas sin administrar servidores.
  • Microsoft Entra Connect: Herramienta que sincroniza usuarios desde un Active Directory on-premises hacia la nube, logrando una identidad híbrida \(hybrid identity\).
  • B2B vs B2C: B2B \(Business-to-Business\) invita a guest users \(proveedores o socios\); B2C \(External ID para consumidores\) permite a clientes registrarse en tus apps públicas.
  • Azure RBAC: Control de acceso basado en roles \(Role-Based Access Control\) que otorga permisos sobre los recursos, aplicando siempre el principio de menor privilegio \(least privilege\).
  • Conditional Access \(Acceso Condicional\): Aplica políticas "si... entonces" al iniciar sesión \(ej. exigir MFA si entras desde un dispositivo no administrado o ubicación inusual\).

    🛡️ Postura de Seguridad y Amenazas

    • Zero Trust & Defense in Depth: Zero Trust exige verificar explícitamente cada solicitud \("never trust, always verify"\); Defense in Depth \(Defensa en profundidad\) protege mediante múltiples capas superpuestas.
    • Microsoft Defender for Cloud: Evalúa continuamente tu postura de seguridad y te otorga un Secure Score con recomendaciones de mejora.
    • Azure Key Vault: Almacén centralizado para proteger secrets \(secretos\), encryption keys \(claves\) y certificates \(certificados\) para que nunca vivan en tu código fuente.
    • Microsoft Sentinel: La solución SIEM nube de Microsoft que recopila, correlaciona logs de múltiples sistemas e investiga incidentes usando inteligencia artificial.
