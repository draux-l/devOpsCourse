☁️ [M09] Azure Fundamentals (AZ-900): Gestión de Costos en Azure

Dominar cómo se factura en la nube es vital tanto para aprobar como para la vida real. Aquí tienen las claves y los nombres oficiales en inglés y español para no caer en las trampas:

💸 Factores de Costo y Facturación

  • El costo de un recurso varía según su región, tamaño y tiempo de ejecución \(uptime\).
  • El tráfico de entrada \(Ingress\) a Azure suele ser gratuito, pero la salida de datos hacia internet \(Egress\) sí genera costos.

    💰 Estrategias de Ahorro

    • Azure Reservations \(Reservas de Azure\): Te dan un gran descuento a cambio de un compromiso de pago de 1 a 3 años. Son ideales para cargas estables 24/7.
    • Spot Virtual Machines \(Acceso puntual\): Usan capacidad sobrante de Azure a un precio muy bajo, pero te las pueden apagar en cualquier momento. Úsalas solo para trabajos interrumpibles \(como procesamiento por lotes o renderizado\).
    • Azure Hybrid Benefit \(Ventaja híbrida\): Te permite reutilizar tus licencias on-premises de Windows Server o SQL Server \(que tengan Software Assurance\) para no pagar doble.

      🧮 Las Calculadoras \(¡No las confundan!\)

      • Azure Pricing Calculator \(Calculadora de precios\): Se usa para estimar el costo mensual de una arquitectura antes de desplegar los recursos.
      • TCO Calculator \(Calculadora de costo total de propiedad\): Se usa para justificar migraciones, comparando lo que gastas hoy en tu datacenter local \(electricidad, refrigeración, hardware\) frente a lo que gastarías en Azure.

        📊 Monitoreo y Gobernanza Financiera

        • Microsoft Cost Management: La herramienta para analizar tu gasto real \(actual spend\), ver facturas pasadas y prever el gasto futuro \(forecast\).
        • Budgets \(Presupuestos\) y Cost Alerts: Puedes definir un umbral de gasto \(ej. 80%\) para que te llegue un correo de alerta. Recuerda: una alerta de presupuesto no apaga ni bloquea tus recursos automáticamente.
        • Resource Tags \(Etiquetas\): Pares clave-valor \(ej. centrocoste=marketing\) para organizar la factura por departamentos. Ojo: Las etiquetas asignadas a un Resource Group no se heredan automáticamente a los recursos que contiene \(necesitas Azure Policy para forzarlo\).

          🎧 Support Plans \(Planes de soporte\)

          • Basic 29$/mes: Gratis, solo ayuda con facturación y foros \(sin soporte técnico telefónico\).
          • Developer 29$/mes: Para pruebas y entornos que no son producción \(horario laboral\).
          • Standard 100$/mes: Soporte 24/7 para cargas en producción.
          • Professional Direct 1000$/mes: Para cargas críticas para el negocio \(business-critical\).
