☁️ [M07] Azure Fundamentals (AZ-900): Azure Storage

Aquí tienen el resumen directo del dominio de almacenamiento para asegurar esos puntos en el examen. ¡Tomen nota de las palabras clave! 📝

🗄️ Servicios Core de Datos

  • 🔐 Cuenta de Almacenamiento \(Storage Account\): Es el recurso principal que exige un nombre globalmente único y cifra todos los datos automáticamente en reposo \(encryption at rest\).
  • 🖼️ Azure Blob Storage: Aloja grandes volúmenes de datos no estructurados como imágenes y backups consumibles por HTTP.
  • 🌡️ Niveles de acceso \(Access Tiers\): Van de Hot para acceso frecuente hasta Archive 🧊, siendo este último offline, el de menor costo y el que requiere horas para rehidratar los datos.
  • 📁 Azure Files: Entrega recursos compartidos \(file shares\) administrados que funcionan directo con los protocolos estándar SMB y NFS.
  • ✉️ Azure Queue Storage: Almacena mensajes asíncronos para desacoplar componentes y absorber picos de carga.
  • 📊 Azure Table Storage: Funciona como un almacén NoSQL clave-valor \(key-value\) de bajo costo y sin esquema fijo.
  • 💿 Azure Managed Disks: Son los discos virtuales administrados exclusivos para el sistema operativo y los datos de las máquinas virtuales.

    🛡️ Estrategias de Redundancia

    • 🏢 LRS: Mantiene 3 copias sincronizadas dentro de un mismo datacenter como la opción más económica.
    • 🏗️ ZRS: Distribuye las 3 copias entre distintas zonas de disponibilidad \(Availability Zones\) para resistir la caída de un edificio entero.
    • 🌍 GRS y GZRS: Replican de forma asíncrona a una región secundaria para disaster recovery sumando 6 copias en total.
    • 📖 RA-GRS y RA-GZRS: Habilitan el Read Access para poder leer los datos en la secundaria sin esperar a que la primaria falle.

      🧰 Herramientas de Migración y Gestión

      • ⌨️ AzCopy: Utilidad de línea de comandos ideal para automatizar con scripts y transferir datos masivos por la red.
      • 🖥️ Azure Storage Explorer: Interfaz gráfica de escritorio gratuita para navegar archivos manualmente.
      • 🔄 Azure File Sync: Mantiene servidores Windows locales sincronizados usando Azure Files como núcleo central en la nube.
      • ✈️ Azure Migrate: Descubre el inventario, realiza la evaluación \(assessment\) y migra cargas locales \(on-premises\) hacia Azure.
      • 📦 Azure Data Box: Dispositivo físico que Microsoft envía para cargar datos de forma offline cuando transferir decenas de terabytes por red tomaría meses.
