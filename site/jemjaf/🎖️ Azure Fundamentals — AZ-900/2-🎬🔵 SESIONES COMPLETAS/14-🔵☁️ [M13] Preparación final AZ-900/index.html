☁️ [M13] Azure Fundamentals (AZ-900): Preparación Final y Tácticas

Llegamos a la recta final. Aquí tienen los trucos definitivos para leer las preguntas y desempatar opciones engañosas:

⏳ El Ritmo: Tienen 45 minutos para 40-60 preguntas. Apunten a 45-60 segundos por pregunta; si se atascan, marquen para revisar y avancen. ¡Nunca dejen una respuesta en blanco!.

🎯 Palabras Gatillo: Si el escenario pide "menor administración", la respuesta es un servicio gestionado \(PaaS/SaaS\). Si pide "recomendado por Microsoft", busquen la respuesta oficial de la documentación, no solo la que "funcione".

⚖️ Desempates Clásicos:

  • ¿RBAC o Policy? Azure RBAC decide quién tiene permisos; Azure Policy decide qué configuraciones están permitidas \(incluso para un Owner\).
  • ¿Cost Management o Pricing Calculator? Cost Management revisa el gasto real que ya tienes; Pricing Calculator estima el costo antes de crear nada.
  • ¿Defender for Cloud o Sentinel? Defender te da recomendaciones de postura de seguridad; Sentinel investiga incidentes como un SIEM.
