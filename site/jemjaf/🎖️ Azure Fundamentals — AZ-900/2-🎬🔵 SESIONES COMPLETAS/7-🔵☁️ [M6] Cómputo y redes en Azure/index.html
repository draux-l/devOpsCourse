☁️ [M06] Azure Fundamentals (AZ-900): Cómputo y Redes

Llegamos al módulo más pesado y técnico del examen. Aquí están las palabras clave exactas para no caer en las trampas de Microsoft:

🖥️ Servicios de Cómputo \(Compute\)

  • Azure Virtual Machines \(VM\): IaaS puro con control total del SO; ideal para lift-and-shift \(tú lo parcheas\).
  • Virtual Machine Scale Sets \(VMSS\): Autoescalado horizontal de máquinas virtuales idénticas según la demanda.
  • Azure App Service: PaaS para web y APIs; tú subes el código, Azure administra el servidor y el SO.
  • Azure Functions: Código serverless ejecutado por eventos \(pagas solo por los segundos de ejecución\).
  • Contenedores: Usa ACI para un contenedor rápido sin orquestador; Container Apps para microservicios serverless; y AKS si necesitas control total de un clúster Kubernetes real.
  • Azure Virtual Desktop \(AVD\): Escritorios Windows en la nube \(soporta multi-session para ahorrar costos\).

    🌐 Servicios de Redes \(Networking\)

    • Azure Virtual Network \(VNet\) & Peering: VNet es tu red privada. El Peering conecta dos VNets por la red troncal de Microsoft, pero recuerda: no es transitivo.
    • NSG & ASG: El Network Security Group \(NSG\) filtra tráfico \(permitir/denegar\) a nivel de red por IP y puerto. El Application Security Group \(ASG\) te permite agrupar esas máquinas por su rol lógico \(ej. servidores web\) para simplificar las reglas del NSG.
    • VPN Gateway vs. ExpressRoute: La VPN conecta tu oficina usando IPsec cifrado a través de internet público. ExpressRoute es una conexión dedicada, privada, con latencia predecible y sin salir a internet.
    • Private Endpoint: Usa Azure Private Link para asignar una IP privada a un servicio PaaS \(como Azure SQL\) y acceder a él sin exponerlo a internet.

      ⚖️ Balanceo y Tráfico \(La clave para diferenciarlos\)

      • Azure Load Balancer: Capa 4 \(TCP/UDP\), distribuye conexiones regionales.
      • Azure Application Gateway: Capa 7 \(HTTP/HTTPS\), regional, enruta por URL y protege con WAF.
      • Azure Front Door: Capa 7, alcance global, con balanceo HTTP, WAF y caché en el borde.
      • Azure Traffic Manager: Alcance global, pero enruta el tráfico usando resolución de nombres DNS.
